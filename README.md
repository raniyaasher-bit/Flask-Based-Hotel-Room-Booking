# Flask-Based Hotel Room Booking Application

This is a Flask-based web application developed using Python and HTML.  
The application is used to manage hotel room details and customer bookings.

## Features
- Add hotel room details
- View available rooms
- Add customer bookings
- View booking records

## Technologies Used
- Python
- Flask
- HTML

## Project Structure
- app.py – Main Flask application file
- templates/ – Contains HTML files
  - add_room.html
  - view_rooms.html
  - add_booking.html
  - view_bookings.html
