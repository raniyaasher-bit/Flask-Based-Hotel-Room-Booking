# Flask-Based Hotel Room Booking Application

Developed a Flask web application using Python and HTML to manage room details and customer bookings.

## Project Overview
This application allows users to add hotel room details, view available rooms, create bookings, and view booking information through a web interface. The backend logic is handled using Flask, and HTML templates are used for rendering pages.

## Features
- Add hotel room details
- View available rooms
- Add customer bookings
- View booking details

## Technologies Used
- Python
- Flask
- HTML

## Project Structure
- app.py – Contains the Flask application logic and routes
- templates/ – Contains HTML files for the user interface

## How to Run the Project
1. Download or clone the repository
2. Make sure Python is installed on your system
3. Open the project folder
4. Run the application using:
   python app.py
5. Open a browser and navigate to:
   http://127.0.0.1:5000/

The application runs locally using Flask’s development server.
